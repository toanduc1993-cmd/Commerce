Phương án triển khai:
State management
Thêm state trong page.tsx:
type RevMode = 'all' | 'latest' | number; // number = REV index (0, 1, 2...) const [selectedRev, setSelectedRev] = useState<RevMode>('all');
Truyền xuống bảng
MasterTrackingTable nhận thêm prop selectedRev. Khi render REV columns:
  • all → hiện REV_COUNT cols như hiện tại
  • latest → chỉ hiện cột REV index cao nhất có data
  • số N → chỉ hiện cột REV N (colSpan=2 thay REV_COUNT×2)
Dropdown UI
Đặt trong toolbar bar chính (thay nút REV:5/16 hiện tại). Nhóm theo dự án, detect số REV thực tế từ data (max revisionNo của PRs trong project đó).
Lưu ý: Hiện tại REV data trong DB chưa có (cột luôn hiện "—"). Feature REV dropdown sẽ có hiệu quả thực tế khi import file Excel có dữ liệu revision. Đề xuất: làm UI trước, hook data sau.
Vấn đề 4

Freeze column bị lệch khi kéo ngang

Phương án khắc phục: CSS Custom Properties (--left-*)
❌ Cách hiện tại (CSS static)
/* Hardcode — sai khi width thay đổi */ sticky left-0 ← Đánh giá (64px) sticky left-16 ← Dự án (96px sau) sticky left-40 ← Item (80px sau) sticky left-60 ← Description
✅ Cách mới (CSS variables tính động)
// Tính offset động trong JS const COL_WIDTHS = { eval: 64, project: 96, item: 80, desc: 176, }; const left = { eval: 0, project: 64, // = eval item: 64 + 96, // = eval + project desc: 64 + 96 + 80, // = ... }; // Truyền qua style={{ left: left.project }}
3 phương án khắc phục — so sánh:
Phương án Mô tả Ưu điểm Nhược điểm Khuyến nghị
A — JS offset object Khai báo const STICKY_OFFSETS = object tính cộng dồn. Dùng style={{ left: STICKY_OFFSETS.desc }} thay left-60 Đơn giản, dễ đọc, không phụ thuộc Tailwind Offset vẫn cứng — không tự động khi width thay đổi theo content Khuyến nghị — phù hợp với bảng width cố định hiện tại
B — useRef + getBoundingClientRect Gán ref cho mỗi sticky col, dùng useEffect để đo width thực và set left động Hoàn toàn chính xác dù width thay đổi Phức tạp hơn, cần re-measure khi window resize hoặc group toggle Dự phòng nếu A chưa đủ
C — CSS subgrid / display:grid Chuyển từ <table> sang CSS Grid với sticky columns Linh hoạt nhất về layout Refactor lớn toàn bộ bảng — riskyy Không làm — quá lớn
Chi tiết Phương án A (JS offset object) — code thay đổi cụ thể
Bước 1: Thêm STICKY_COLS constant
// Khai báo trên component — ngoài function body const STICKY_W = { eval: 32, // w-8 = 32px (thu gọn từ 64 — chỉ còn KQ icon) project: 96, // w-24 item: 80, // w-20 desc: 176, // w-44 }; // Tính offset cộng dồn const STICKY_LEFT = { eval: 0, project: STICKY_W.eval, item: STICKY_W.eval + STICKY_W.project, desc: STICKY_W.eval + STICKY_W.project + STICKY_W.item, }; // = { eval:0, project:32, item:128, desc:208 }
Bước 2: Sửa th/td sticky dùng style thay className
/* Trước */ <th className="... sticky left-16 z-40 ..."> /* Sau */ <th className="... sticky z-40 ..." style={{ left: STICKY_LEFT.project }} > /* Tất cả 4 sticky cols: eval → style={{ left: STICKY_LEFT.eval }} = 0 project → style={{ left: STICKY_LEFT.project }} = 32 item → style={{ left: STICKY_LEFT.item }} = 128 desc → style={{ left: STICKY_LEFT.desc }} = 208 */
